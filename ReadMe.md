# JDM Tax Calculator

FastAPI backend.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
uvicorn app.main:app --reload
```

- API: http://127.0.0.1:8000/
- Health check: http://127.0.0.1:8000/health
- Interactive docs: http://127.0.0.1:8000/docs
